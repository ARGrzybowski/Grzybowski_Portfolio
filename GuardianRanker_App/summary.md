# Guardian-Ranker – Destiny 2 Stats & Leaderboards

## Overview
Guardian-Ranker is a web application designed for Destiny 2 players and enthusiasts. It allows users to search for player stats, compare them across leaderboards, and view global season information with a live countdown to weekly resets. The project integrates the Bungie API for real-time player and season data and uses Supabase to power leaderboard management.  

## Key Features
- **Player Stat Search:** Look up detailed stats for Destiny 2 players by username.  
- **Dynamic Leaderboards:** Automatically ranks searched players for direct comparison.  
- **Season Tracking:** Displays current season details, its duration, and a live countdown to the next weekly reset.  
- **Browser-Based:** No installation required—runs in any modern browser.  

## Skills Demonstrated
- Frontend development with **HTML, CSS, and JavaScript**  
- Backend integration with **Supabase**  
- API consumption and data handling with the **Bungie API**  
- Responsive UI/UX design  
- Full-stack project deployment and maintenance
